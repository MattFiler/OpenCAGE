<h2 align="center">Open-source mod tools for Alien: Isolation</h2>

<p align="center">
  <b>OpenCAGE is an extensive open-source modding toolkit for Alien: Isolation which unlocks the ability to fully customise and build new levels, missions, modes, characters, props, weapons, behaviours, UIs, and more!</b>
</p>

<p align="center">
  <a href="https://store.steampowered.com/app/3367530/OpenCAGE/"><img alt="Get it on Steam" src="https://img.shields.io/badge/Steam-Download%20free-1b2838?style=for-the-badge&logo=steam"></a>

</p>

  <h3>Browse Levels in a 3D Viewport</h3>
  <p>Open any level and fly through it. Click anything you see to find it in the level&rsquo;s scripts, move and rotate it with the gizmo, or drag new content in straight from the Composite Browser.</p>
  <p><a href="https://opencage.co.uk/docs/level-viewer/"><b>Viewport guide &rarr;</b></a></p>

  <br>
  <h3>Edit Existing Game Scripts</h3>
  <p>Alien: Isolation runs on thousands of CATHODE scripts. Open any of them as a flowgraph laid out over pages, then rewire it, delete what you don&rsquo;t need and tune any parameter in the inspector.</p>
  <p><a href="https://opencage.co.uk/docs/scripting-intro/"><b>Introduction to scripting &rarr;</b></a></p>
</div>
<br clear="all" />

<div>
  <img align="left" width="55%" src="https://github.com/user-attachments/assets/b1befa00-5034-4b2c-881b-f887627c0256" alt="Building a script for entering a trigger box">
  <br>
  <h3>Build Your Own Scripts</h3>
  <p>Drag any of the game&rsquo;s entity types from the Entity Palette onto a graph and link up their pins. Trigger volumes, markers and props go straight into the world from the Viewport&rsquo;s Create menu.</p>
  <p><a href="https://opencage.co.uk/docs/cathode-entities/"><b>Available script entities &rarr;</b></a></p>
</div>
<br clear="all" />

  <img align="right" width="55%" src="https://github.com/user-attachments/assets/65976d6c-d0eb-4f6a-9dad-13a75e0a4a9d" alt="Show Activity lighting up links and counting pin calls in the editor while driving an in-game debug marker">
  <h3>Debug Scripts at Runtime</h3>
  <p>With Live Link connected, Show Activity lights up each link as it fires and counts every call on its pins. Trigger any method from the inspector to test a script without playing up to it, set breakpoints on nodes to stop the game&rsquo;s scripts and step through them, and put values on screen in game with debug text and position markers.</p>
  <p><a href="https://opencage.co.uk/docs/live-link/"><b>Live Link &rarr;</b></a> &nbsp;&middot;&nbsp; <a href="https://opencage.co.uk/docs/debug-text/"><b>Debug text and markers &rarr;</b></a></p>
</div>
<br clear="all" />

  <br>
  <h3>Create and Modify Scripted Keyframes</h3>
  <p>Open any CAGEAnimation to edit its tracks on a curve editor: drag keys and bezier handles, add new tracks, and switch on Animation Mode to scrub the result in the Viewport.</p>
  <p><a href="https://opencage.co.uk/docs/cage-animation-editor/"><b>CAGEAnimation editor &rarr;</b></a></p>
</div>
<br clear="all" />

  <br>
  <h3>Import, Export, and Preview Animations</h3>
  <p>Preview any clip on its character&rsquo;s own model, export clips or import your own, and edit the animation trees that blend them together.</p>
  <p><a href="https://opencage.co.uk/docs/animation-editor/"><b>Animation Editor &rarr;</b></a> &nbsp;&middot;&nbsp; <a href="https://opencage.co.uk/docs/animation-tree-editor/"><b>Animation Tree Editor &rarr;</b></a></p>
</div>

  <br>
  <h3>Live Edit Scripts In-Game</h3>
  <p>Live Link connects OpenCAGE to the game while it runs. Place and move props, change lights, tweak scripts and call methods, and the game updates without a reload. The game camera can follow the Viewport, so you see every edit from the same angle.</p>
  <p><a href="https://opencage.co.uk/docs/live-link/"><b>Live Link &rarr;</b></a></p>
</div>
<br clear="all" />

  <br>
  <h3>Import, Export, and Preview Models</h3>
  <p>Import your own models with a 3D preview and a scale check, then browse, export and edit any mesh in the game from the Model Editor.</p>
  <p><a href="https://opencage.co.uk/docs/model-editor/"><b>Model Editor &rarr;</b></a></p>
</div>

  <p>Change a material&rsquo;s shader, samplers and parameters, and browse, export and replace any texture in a level.</p>

  <p><a href="https://opencage.co.uk/docs/create-level/"><b>Creating a level &rarr;</b></a> &nbsp;&middot;&nbsp; <a href="https://opencage.co.uk/docs/save-and-build/"><b>Save and Build &rarr;</b></a></p>

  <h3>Film the Game with a Cinematic Camera</h3>
  <p>With the Debug Menu ticked in Launch Game, fly its free camera anywhere in the level, drop camera track nodes along the way and play them back as one smooth move. The Cinematic group also sets depth of field and colour, hides the HUD and takes screenshots.</p>
  <p><a href="https://opencage.co.uk/docs/debug-menu/#free-camera"><b>Free camera &rarr;</b></a> &nbsp;&middot;&nbsp; <a href="https://opencage.co.uk/docs/debug-menu/#camera-tracks"><b>Camera tracks &rarr;</b></a></p>
</div>

  <h3>See Inside the Game with the Debug Menu</h3>
  <p>With Debug Menu ticked in Launch Game (it is by default), press <code>F7</code> in game. Draw every character&rsquo;s view cones and alertness over the game, show the nav mesh the AI walks on, and point a crosshair at anything to read its collision, materials and model.</p>
  <p><a href="https://opencage.co.uk/docs/debug-menu/"><b>Debug Menu &rarr;</b></a></p>
</div>
